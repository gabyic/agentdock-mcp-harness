# 09 — Real ChatGPT Web + Leapscall product Acceptance

Blocked by: 08

## Goal
Use the actual product surface to prove the AgentDock product hypothesis.

## Acceptance criteria
- AgentDock runs on the current Leapscall Linux server.
- Public connectivity is provided outside Core by the chosen secure MCP connection/tunnel layer.
- Use an independent real Git test repo, not production repositories.
- The formal Task is initiated from real ChatGPT Web.
- The Task completes inspect/worktree/read/search/patch, real test FAIL, failure-driven second edit, real connection interruption, resume, ChatGPT Smart Approval, targeted PASS, full suite PASS, real commit SHA, finish, and audit.
- After task.create there are zero Leapscall SSH fallback development actions.
- There is no second LLM and no server AI API key.
- Source repo remains zero-pollution.
- sudo capability is only a safe smoke test and is not a Core PASS prerequisite.

## Demo
From ChatGPT Web, ask to fix the prepared bug and complete the entire remote professional coding-harness loop through AgentDock alone.

# AgentDock v0.4.0-dev.2

Date: 2026-09-23

This development build delivers the Guarded Execution integrity and safety line derived from the production audit.

## Added

- Durable Task outcomes with COMMIT / NO_CHANGE evidence and AgentDock-owned Git refs that survive worktree cleanup and Git GC.
- Optional transactional SQLite state backend using built-in node:sqlite with WAL, transactions, schema versioning, idempotent JSON import, and cross-process mutation safety.
- task.list for discovering ACTIVE, finalized, stale, and cleanup state without automatic deletion.
- Evidence-gated Guided Workflow completion tied to implementation Task outcomes and Standards / Spec review evidence.
- Guarded Execution deep module with Workspace and Host lanes.
- off / observe / enforce rollout modes.
- Bubblewrap Workspace sandbox with read-only host root, writable Task worktree, isolated namespaces, dropped capabilities, hidden paths, temporary HOME, and configurable network policy.
- MCP 2026-07-28 input_required human confirmation for Host process and absolute host file mutations.
- Explicit legacy Approval compatibility path that requires deterministic ask policy.
- Guarded Execution doctor diagnostics and rollout documentation.

## Changed

- Process live output is byte-bounded and durable command/output previews are bounded and redacted.
- Task, Approval, Audit, Workflow, and persisted Process mutations share the StateStore seam.
- SQLite connection startup waits on contention before WAL setup.
- MCP tool count is now 32 because task.list is part of durable Task hygiene.

## Safety

- JSON remains the default state backend.
- Guarded Execution remains off by default.
- Production enforcement is not enabled automatically.
- Enforce fails closed when the sandbox runtime is missing or below the supported security minimum.
- The audited production host currently has Bubblewrap 0.9.0, so enforce must remain disabled until the runtime is upgraded and revalidated.

## Migration

See docs/guarded-execution.md. SQLite migration requires a maintenance-window state backup; SQLite becomes the canonical writer after migration and rollback requires restoring the pre-migration backup rather than simply switching back to JSON.

## Distribution

npm publication remains disabled. Release artifacts continue to use the verified GitHub Release path.

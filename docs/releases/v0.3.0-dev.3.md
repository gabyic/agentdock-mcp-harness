# AgentDock v0.3.0-dev.3

Date: 2026-09-23

Auto Matt Routing lets one `@AgentDock` App choose and load the installed Matt
engineering workflow automatically after the user has explicitly enabled that
mode. No second MCP and no server-side LLM are introduced.

## Behavior

```text
@AgentDock + software-engineering request
  -> skill.invoke(skill_name="auto")
  -> Ask Matt routing instructions + candidates + workflow state
  -> chat model selects the appropriate Skill
  -> skill.invoke(selected Skill)
  -> deterministic AgentDock execution tools
```

Auto routing is default-off. Enable it with:

```bash
AGENTDOCK_MATT_AUTO_ROUTING=true
```

or configuration field `skills.matt_auto_routing=true`.

Upstream user-invoked Skills are admitted only under explicit human invocation
or this user-granted Auto Matt mode. Auto-authorized calls are labeled
`auto_authorized` in the invocation result.

## Safety boundary

- ChatGPT/Claude remains the only reasoning model.
- AgentDock never evaluates `SKILL.md` as executable code.
- Auto Matt cannot invent unresolved product decisions.
- AgentDock approval and OS-permission boundaries remain unchanged.
- Durable workflow phase boundaries remain fail-closed.
- MCP tool count remains 31.

## Distribution

npm publication remains disabled. Release artifacts continue to use the existing verified GitHub Release path.

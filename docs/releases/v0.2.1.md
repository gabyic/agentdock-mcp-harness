# AgentDock MCP Harness v0.2.1

> **无限流 / Infinite Coding Flow** — use your existing ChatGPT / Claude Web quota for remote coding without a second server-side API token meter.

v0.2.1 is a release-engineering patch on the v0.2 stable maintenance line. It does **not** contain v0.3 Guided Development, skill, or workflow functionality.

## Why this patch exists

The original v0.2.0 release contents and tag remain intact, but GitHub did not enforce native Release Immutability for that already-published release. v0.2.1 fixes the publication path for future stable releases without rewriting v0.2.0.

## Release hardening

- The release workflow refuses to overwrite an existing mutable release.
- Asset `--clobber` behavior is removed.
- After publication the workflow requires GitHub to report `immutable: true`.
- The release tag must resolve to the exact workflow commit.
- Uploaded tarball and checksum asset digests must match the locally built SHA-256 digests.
- If a newly published release remains mutable after bounded propagation retries, the workflow deletes that failed release and its new tag instead of leaving a mutable release behind.
- The normal release gate still covers full tests, v0.1 acceptance, dependency audit, systemd contract verification, reproducible artifacts, checksum validation, and extracted-install smoke testing.

## Required repository setting

Before creating the `v0.2.1` tag, GitHub repository **Settings → Releases → Enable release immutability** must be enabled. GitHub applies this protection only to future releases.

Do not recreate, move, delete, or reuse `v0.2.0`.

## Runtime scope

There are no intentional AgentDock runtime or MCP behavior changes in this patch. The v0.2 runtime contract remains unchanged.

## Installation

Download both release assets and verify the checksum:

```bash
sha256sum -c agentdock-mcp-harness-v0.2.1.tar.gz.sha256
tar -xzf agentdock-mcp-harness-v0.2.1.tar.gz
cd agentdock-mcp-harness-0.2.1
./scripts/install.sh
```

Then verify:

```bash
agentdock version
agentdock doctor
```

For native HTTP:

```bash
agentdock health --url http://127.0.0.1:3100/healthz
```

## Known boundaries

- Linux is the supported execution host.
- macOS and Windows execution backends are not included.
- Public TLS/OAuth ingress remains an external deployment responsibility.
- AgentDock inherits native OS permissions; it is not a sandbox.
- No autonomous Codex/Claude/OpenCode worker or server-side LLM is included.
- Push/merge/PR/deploy are not first-class Core primitives.
- npm publication remains disabled.

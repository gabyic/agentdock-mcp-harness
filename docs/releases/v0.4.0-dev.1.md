- SQLite production authority, fail-closed state cutover, complete backup verification, and safety-ref-based worktree recovery.

## Architecture

The MCP surface contains 42 explicit tools. AgentDock now has a Single Run Supervisor execution seam: one dedicated daemon owns child-process handles, while HTTP, stdio/MCP, OAuth, and tunnel-facing runtimes delegate Run start, status, output, and cancellation over a Unix domain socket. SQLite is the authoritative multi-process state store. Persisted PIDs are diagnostic only and never authorize signals.

Durable Plans execute only caller-declared deterministic steps and explicit barriers; no second server-side LLM or hidden reasoning loop is added.

The unresolved distribution decision is intentionally not guessed: public release must choose between an OpenAI-approved Template/self-hosted topology and a Universal publisher-controlled endpoint with a relay/control plane.

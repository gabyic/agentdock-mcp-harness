# AgentDock MCP Harness v0.3.0-dev.1

This development build starts the v0.3 Guided Development line on top of stable v0.2.0. It is not a stable v0.3 release and is intended for live validation before an RC is cut.

## Guided Development

- Git-backed server-side skill resources: `skill.install`, `skill.update`, `skill.list`, `skill.search`, and `skill.read`.
- Durable project workflow state: `workflow.start`, `workflow.list`, `workflow.update`, `workflow.guide`, and `workflow.advance`.
- Compatibility with Matt Pocock's engineering-skills workflow while keeping ChatGPT/Claude Web as the reasoning agent.
- Cross-chat project recovery, source commit evidence, first-use setup checks, phase-boundary enforcement, and unresolved-decision guards.

## Architecture boundary

Skills remain instruction resources. AgentDock does not add `skill.execute`, a server-side LLM, or an autonomous agent loop.

## Validation

This development line retains the v0.2 protocol, lifecycle, release, service-recovery, and v0.1 black-box regression suites and adds v0.3 skill/workflow coverage.

## Publication

npm publication remains disabled for this development build.

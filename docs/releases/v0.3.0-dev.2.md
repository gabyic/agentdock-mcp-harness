# AgentDock v0.3.0-dev.2

Date: 2026-09-23

This development build makes server-side Skills first-class through the same
AgentDock MCP/App boundary without turning them into server-executed agents.

## Added

- `skill.invoke`: explicit Skill invocation contract for ChatGPT/Claude Web.
- User/model invocation enforcement for upstream `disable-model-invocation`.
- Optional workflow context attached to Skill invocation.
- `workflow.status`: stable, read-only workflow inspection.

## Architecture

```text
Chat model
  -> @AgentDock
       -> Skill Resource Layer (Matt-compatible instructions)
       -> Guided Workflow State
       -> Execution Harness (files / shell / git / tests / process / audit)
```

The chat model remains the reasoning agent. AgentDock never evaluates a
`SKILL.md`, never launches a second LLM for Skill execution, and never allows a
user-invoked Skill to be reached implicitly.

## Compatibility

Existing `skill.read`, `workflow.guide`, Task, process, Git, approval, and audit
tools remain available. The MCP tool surface grows from 29 to 31 tools.

## Distribution

npm publication remains disabled. Release artifacts continue to use the existing verified GitHub Release path.
